# 手机操作与边界

1. 安装 `signer/dist/nwallet-0.3.1/NWallet.jar`，需要时使用配套 JAD。
2. 首次设置并重复确认4–12位数字 PIN，保留前导零。连续5次错误冷却30秒；这是样本应用锁，计数在进程内，不是生产根密钥保护。
3. 设置中进入“创建样本根钱包”，上下选择12／24词公开样本，右软键创建。更换根会断开连接并清理打开缓存。
4. 首页中键开启服务，在网页手工选择设备连接，再在手机允许本次连接。
5. 网页点击添加或打开，输入公开测试 passphrase。手机上下查阅，左拒绝／右确认，中键不批准。派生中左软键取消，结果页右返回。
6. 网页核对实际三链地址后保存记录；已知完整缓存命中时不再发送 passphrase。

首页左右切换首页／设置／介绍；左软键锁定，右软键退出。Language上下仅移动焦点，中键或右软键选定并保存，左返回。

普通断连和锁定保留完整内存缓存；后台返回要求 PIN；真正退出清理全部缓存。不要将 Java 字符串释放或 GC 视为取证级内存擦除。

界面展示使用浅绿白底、小图标Tab、哑光功能块和局部高光。红色未授权、蓝色已授权，同时保留状态文字。设备字体、软键位置、性能和无线效果由用户手工验收。
