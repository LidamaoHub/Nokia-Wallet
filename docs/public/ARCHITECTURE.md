# 架构与协议

## 组件

浏览器 → Next.js 本机 API → stdin/stdout JSON IPC → Swift Mac 桥接 → 经典蓝牙 RFCOMM → Java ME 手机端。

网页采用 shadcn/ui Nova、Lucide 与 Motion，钱包优先三栏布局。手机界面独立采用 N-Gage 风格，目标240×320，由实际 Canvas 宽高与设备字体测量绘制。

手机端根材料只来自内置公开零熵样本；网页不接收根助记词或私钥。网页传入的 passphrase 只能用于公开样本测试，保留空串、大小写和首尾空格，最多50个可打印 ASCII 字符。

## 连接与钱包请求

服务发现优先读取确切服务 UUID 的系统缓存；缓存通道失效后执行有界刷新。每次新 HELLO 都需要手机授权，READY 前不接受钱包业务。系统配对与应用授权是不同层次。

NKB1 为有界外层传输；NKS2 READY 参数4、正文 `PING1|WALLET2` 表示钱包能力。钱包帧15／16／17／18分别为命令、结果、进度、错误。正文采用 UTF-8／LF，包含协议标识 `NWALLET2`、操作及请求 UUID。

- INFO：当前公开样本根、词数、缓存数。
- CHECK：按根和完整地址束指纹查询缓存，不发送 passphrase。
- OPEN：绑定根、期望地址束指纹及原样 passphrase；用户在手机右软键确认后才复用缓存或实际派生。
- CANCEL：请求协作取消；原操作终态才表示取消完成。

指纹为规范 NKW1 三链地址束的 SHA256；包含词数、路径及实际地址。ETH使用 EIP-55；BTC／SOL保留 Base58 大小写。地址不匹配不覆盖已有记录。

相同 UUID 与相同正文可重取已完成结果，冲突拒绝；无完成结果重新确认。手机缓存上限8个钱包，回执上限16个，FIFO淘汰。断连或锁定撤销未完成批准并保留完整缓存；退出或更换根清理缓存。

CRC、UUID与应用确认不是密码学身份认证，也不构成防劫持保证。打开钱包不批准交易，当前没有签名或广播能力。

## 本地存储与 API

网页 AES-256-GCM 样本库以随机数据密钥加密；长密码经 PBKDF2-SHA256 封装数据密钥。解锁后记录在内存，只有加密数据写入持久化存储。

闲置15分钟锁定；同标签页时限内刷新可恢复。恢复凭据位于 sessionStorage，数据密钥仅留本地 Node 进程内。主动锁定、超时或服务重启撤销恢复能力。阅后即焚为每钱包属性；正常结束删除持久化记录，无法恢复的异常退出在下次解锁补删。

`/api/local` 使用 GET读取本地能力、POST执行白名单动作；`/api/wallet-session` 使用 POST管理样本会话。仅允许固定本机3018同源请求，跨域需要时允许 OPTIONS。没有 PUT／PATCH／DELETE 接口。

原生 Touch ID 通过 LocalAuthentication 与独立 Keychain 命名空间保存样本库数据密钥，不保存长密码；硬件行为需本机手工验证。
